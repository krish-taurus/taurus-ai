# Taurus Terminology

Taurus must feel like a workforce platform, not an AI developer tool.

| Generic Term | Taurus Term | Meaning |
|---|---|---|
| Agent | AI Employee | A persistent AI worker owned by a company |
| Agent Builder | Hiring Studio | The no-code flow to create an AI employee |
| Prompt | Employee DNA | Structured configuration for behavior, role, tone, policy, and knowledge |
| Knowledge Base | Knowledge Vault | Approved knowledge an employee can use |
| Tool | Skill | Capability available to an AI employee |
| Workflow | Responsibility | A job duty assigned to an employee |
| Session | Shift | A work session or interaction window |
| Agent Marketplace | Workforce Marketplace | Place to hire/install specialized AI employees |
| Agent Profile | Employee Card | Public or private AI employee profile |
| Multi-Agent System | AI Team | Group of AI employees working together |
| Memory | Experience | Long-term history and learning context |
| Agent-to-Agent | Employee Collaboration | Controlled collaboration between AI employees |

## UI language rule

Business users should never be forced to understand:

- embeddings,
- chunking,
- vector search,
- RAG,
- top-k,
- temperature,
- system prompts.

These belong in internal developer documentation, not the default UI.
