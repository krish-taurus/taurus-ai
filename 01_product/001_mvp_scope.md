# MVP Scope

## MVP Promise

An enterprise user can hire and collaborate with AI employees in five minutes.

## Primary User

A non-technical business user inside an enterprise.

This user cares about outcomes, not AI configuration.

## Included in MVP

- User signup and login
- Organization workspace
- Organization members and roles
- AI Employee creation
- Hiring Studio
- Employee DNA configuration
- Employee Card
- Knowledge Vault file upload
- Basic document processing
- Basic RAG chat
- Internal employee collaboration
- Audit logs
- Usage tracking
- Simple dashboard

## Excluded from MVP

- Public marketplace transactions
- Fully autonomous cross-company collaboration
- Production phone/voice calling
- Advanced workflow automation
- Enterprise SSO
- SOC 2 / HIPAA certification
- Advanced billing automation
- Mobile app
- Full multi-model routing
- External CRM/ERP integrations

## MVP Completion Criteria

A pilot customer can:

1. sign up,
2. create an organization,
3. hire an AI employee,
4. upload company knowledge,
5. ask the employee a question,
6. receive an answer grounded in knowledge,
7. create an internal collaboration request,
8. review audit logs,
9. see basic usage.

## Success Metrics

- Time to first employee: under 5 minutes
- Time to first useful answer: under 10 minutes
- Pilot setup completion rate: 60 percent or higher
- User satisfaction after first setup: 8 out of 10 or higher
- Hallucination incidents: tracked and reviewed
