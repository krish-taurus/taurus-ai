# User Journeys

## Journey 1: Hire First AI Employee

### Goal

A business user creates their first AI employee without technical help.

### Steps

1. User signs up.
2. User creates organization.
3. User lands on empty workspace.
4. User clicks "Hire AI Employee."
5. User selects a role.
6. User uploads documents or skips this step.
7. User chooses responsibilities.
8. User chooses tone.
9. User reviews Employee DNA summary.
10. User clicks "Hire Employee."
11. Employee appears on dashboard.

### Desired feeling

"I automated work with a few clicks."

## Journey 2: Create Internal Knowledge Employee

### Goal

Create an employee that answers internal company questions.

### Steps

1. User selects Internal Knowledge Assistant.
2. User uploads PDFs, SOPs, FAQs, and policy documents.
3. Taurus processes files into the Knowledge Vault.
4. User asks test questions.
5. Employee answers with citations.
6. User invites team members.

## Journey 3: Internal Collaboration

### Goal

One AI employee asks another AI employee for help.

### Example

Support AI receives a billing question.

Support AI sends a Collaboration Request to Finance AI.

Finance AI answers using its own approved Knowledge Vault.

Support AI uses that answer to respond to the user.

All steps are logged.

## Journey 4: Future Cross-Company Collaboration

### Goal

An AI employee at Company A asks a specialist AI employee at Company B for advice.

### Required future controls

- Explicit publishing settings
- Partner allowlists
- Topic-level permission policies
- Human approval
- Billing consent
- Audit trail
- Revocation
- Data retention controls

This is not fully implemented in MVP.
