# Prompt 004: Hiring Studio

## Objective

Build the guided five-minute flow to hire an AI employee.

## Route

`/dashboard/hire`

## Steps

1. Choose role
2. Add knowledge
3. Define responsibilities
4. Choose tone
5. Review Employee DNA
6. Hire Employee

## Requirements

- Use simple language.
- Save progress locally or in draft state.
- Allow skipping knowledge upload.
- Generate default DNA from role template.
- Create employee and active DNA on completion.
- Redirect to Employee Card.

## Completion copy

> Your AI employee is ready for work.

## Acceptance criteria

- User can complete flow in under five minutes.
- Employee and active DNA are created.
- User does not see raw prompt fields.
